# Render Deployment (Free Demo)

`render.yaml` at the repository root is a Render Blueprint. It creates three free resources in the Singapore region:

| Resource | Type | What it runs |
| --- | --- | --- |
| `nagarflow-db` | PostgreSQL 16, free | The database |
| `nagarflow-trichy-api` | Docker web service, free | `backend/Dockerfile` |
| `nagarflow-trichy` | Static site | `frontend/`, built with `npm run build`, with the same headers as `nginx.conf` |

## How it differs from the compose package

- **The roads file is downloaded, not mounted.** The free plan has no disk. On every start, `backend/scripts/fetch_roads.py` downloads the GeoPackage from `ROAD_NETWORK_URL`, a GitHub Release asset, checks it against `ROAD_NETWORK_MD5`, and then starts the API. With the compose file, `ROAD_NETWORK_URL` is unset and the script does nothing.
- **The database address** Render gives starts with `postgresql://`. The backend rewrites that to `postgresql+psycopg://` itself.
- **Email is off.** `SMTP_HOST` is `smtp.invalid`, so password-reset requests answer as usual but no email is sent. The failure is logged. Render's free plan also blocks outbound SMTP ports, so real email needs a paid instance or an HTTP mail API.
- **The JWT secret** is generated by Render (`generateValue`) and never written down.

## Free-plan limits

- **512 MB of memory.** The deployment guide measured about 585 MiB after one optimization of S01, so an optimization may be killed. `OPTIMIZER_MAX_CONCURRENT` is 1 to keep this down. If runs fail with the service restarting, move the API to a 2 GB instance.
- **The API sleeps** after 15 minutes without requests. The first request then takes about a minute while it wakes and downloads the roads file again.
- **The free database is deleted 30 days after it is created.** Upgrade it, or export the data before then.

## Addresses

The addresses in `render.yaml` assume Render uses each service name as its `onrender.com` subdomain. If a name was taken and Render added a suffix, change `CORS_ORIGINS`, `FRONTEND_BASE_URL`, `VITE_API_BASE_URL` and the Content-Security-Policy to the real addresses, and sync the Blueprint again.

## Smoke check

```bash
python backend/scripts/smoke_check.py --api https://nagarflow-trichy-api.onrender.com --frontend https://nagarflow-trichy.onrender.com
```
